Evidence labels

Every strategy carries one of four labels, so you can tell how close the version here is to what was published.

LabelMeaningWhat it lets you conclude
Published, replicableThe method is public and can be reproduced on data we can use.Our numbers can be checked against the paper’s.
Published, data restrictedThe method is public, but the paper used licensed data (for example CRSP stock files), so ours differ.A test of the published idea on different data, not a replication.
Public description onlyOnly what a firm says about itself; never code or parameters.Nothing about performance. No strategy on this site currently carries this label.
DefinitionA benchmark defined by construction.A yardstick; it makes no claim.

Rules the site follows: nothing that cannot be checked is presented as fact; every backtest is labelled hypothetical and every simulation labelled as a simulation; when a detail of a paper could not be confirmed, the page says so instead of guessing.

Confirmation levels for each parameter

For each number or rule we use: was it confirmed from the paper’s own text, only from a secondary source, or not at all? Our own adaptations, needed because monthly industry data differ from the papers’ data, are listed too. Checked on 30 September 2026.
