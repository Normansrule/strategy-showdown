Open-source terminals and tools

Professional market terminals are expensive and closed. A lot of what they do, research platforms, backtesting engines, analytics, pricing libraries and charting, now has open-source counterparts. This page lists the main ones, including the projects Bloomberg itself publishes as open source, with each licence read from the project’s own licence file.

How to read the licence column. Permissive licences (MIT, BSD, Apache-2.0) let you reuse code with attribution. Copyleft licences (GPL, AGPL, LGPL) require you to share changes, and AGPL extends that to software offered over a network. “Custom” means extra conditions beyond a standard licence: read them before using the code. Licences were checked on the date shown and can change; this is not legal advice.

What this project uses

  • Apache ECharts (Apache-2.0) draws every chart; KaTeX (MIT) typesets the equations. Both are vendored with their licence files and checked against pinned SHA-256 hashes.
  • Electron (MIT) wraps the same pages as the desktop app.
  • No code is copied from the projects above. Ideas such as metric definitions (QuantStats), engine structure (backtesting.py, Zipline) and data-provider patterns (OpenBB) are re-implemented from the published papers and our own specification, so copyleft licences such as AGPL do not apply to this project.
