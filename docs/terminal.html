Terminal

A keyboard-driven way to use everything on this site: type a command, press Enter. Type help to start. Everything runs in your browser on the same engine as the other pages; nothing is sent anywhere.

A terminal-style interface in the spirit of professional market terminals. Not affiliated with, endorsed by, or modelled on the commands of Bloomberg L.P. or any other terminal vendor; the command names are this project’s own. Educational, hypothetical results only.
