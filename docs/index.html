Same data, same months, same costs

Pick trading rules that researchers have published, and this page runs them side by side on one dataset, over one evaluation window, under one cost model. The statistics include the corrections that are usually left out: uncertainty ranges, costs, and a penalty for trying many variants. Every number is a hypothetical backtest: what the rule would have done on past data, not what anyone earned.

    Run it on your own computer

    With a copy of the repository, run python scripts/fetch_french.py. It writes docs/data/local/french.json, which this page loads automatically when served locally. That file is ignored by git and never published.

    Hypothetical backtest

    What is it really exposed to?

    A regression of each strategy’s excess return on standard risk factors. A beta is how much the strategy moves when that factor moves by 1. Alpha is the average monthly return the factors do not explain.

    Engine notes

    Events the engine recorded while running each strategy: fallbacks, degenerate estimates, wipe-outs.
